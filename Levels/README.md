# Уровни

Каждый файл `*.json` в этой папке становится пунктом меню Level. В меню пишется имя файла без расширения `.json`. `README.md` в список не попадает.

Enter в этом меню только запоминает уровень и возвращает в главное меню. Партию запускает пункт Game: он берёт уровень, выбранный последним. Если уровень ещё не выбирали, при старте берётся первый файл по алфавиту.

## Сетка

Блоки стоят не по пикселям, а по клеткам. Левый верхний угол клетки:

- `x = column * 90`
- `y = 64 + row * 28`

Ширина блока 80, высота 18, зазор между клетками 10. Нумерация с нуля.

Верхняя половина поля заканчивается на `y = 300`. Блок должен поместиться в неё целиком, поэтому сейчас допустимы:

- `column` от 0 до 8
- `row` от 0 до 7

Столбцы 0 и 8 упираются в левый и правый край экрана. Ряд 7 — самый нижний ряд верхней половины. Две клетки с одним и тем же `column` и `row` писать нельзя.

## Файл

Корень — объект с массивом `blocks`.

```json
{
  "blocks": [
    { "type": "smooth", "column": 2, "row": 1, "color": [220, 82, 86] },
    { "type": "durable", "column": 3, "row": 1, "color": [168, 112, 214], "hits": 3 },
    { "type": "glass", "column": 5, "row": 1 },
    { "type": "unbreakable", "column": 1, "row": 1 }
  ]
}
```

`type`:

| type | Что это | Обязательные поля |
|---|---|---|
| `smooth` | Обычный блок, гаснет за секунду | `column`, `row`, `color` |
| `durable` | Ломается с нескольких ударов | `column`, `row`, `color` |
| `glass` | Прозрачный, шарик пролетает сквозь него | `column`, `row` |
| `unbreakable` | Не ломается и не нужен для победы | `column`, `row` |

`color` — три целых числа от 0 до 255, `[красный, зелёный, синий]`. Для `glass` и `unbreakable` цвет не задаётся: у них свой вид.

`hits` есть только у `durable`. Это целое число от 1. Если поле пропустить, у блока будет 3 удара.

Готовые примеры: `classic.json` и `wide.json`.
